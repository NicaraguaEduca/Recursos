📜 Guía para el Docente

Propósito: Desarrollar el Recuerdo Activo de la secuencia alfabética.

Desafío: El niño debe identificar el orden lógico sin pistas textuales.

Andamiaje: Tras 3 errores, el sistema ofrece un refuerzo musical automático.

Recomendación: Permita que el niño se equivoque; el error es parte del aprendizaje.
